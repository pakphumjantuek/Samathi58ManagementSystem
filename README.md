# ระบบบริหารจัดการสถาบันสอนสมาธิ (Samathi 58 Management System)

เว็บแอปพลิเคชันสำหรับบริหารงานทะเบียนและการเรียนการสอนของสถาบันสอนสมาธิ ตั้งแต่ข้อมูลหลักสูตร นักศึกษา รุ่นเรียน ตารางเรียน การเช็กชื่อ ไปจนถึงออกบัตรนักศึกษา ตารางเรียน PDF และรายงาน Excel พัฒนาด้วย Blazor Server

## ระบบนี้ทำอะไรได้

| กลุ่มงาน | สิ่งที่ทำได้ |
|---|---|
| **ข้อมูลหลัก** | จัดการสาขา คำนำหน้าชื่อ ตำแหน่งงาน หลักสูตร อาจารย์ และประวัติการศึกษา |
| **นักศึกษา** | ทะเบียนนักศึกษา และออกบัตรนักศึกษาเป็น PDF |
| **รุ่นและตารางเรียน** | จัดการรุ่นเรียน ดูตารางเรียน ออกตารางเรียนเป็น PDF และสรุปรุ่นเป็น Excel |
| **แผนการเรียน** | จัดการแผนการเรียนของหลักสูตร **นำเข้าจากไฟล์ Excel** (.xls / .xlsx) และส่งออกเป็น PDF |
| **เช็กชื่อ** | บันทึกการเข้าเรียนรายครั้ง และสรุปรายงานการเข้าเรียนเป็น Excel |
| **รายงานและแดชบอร์ด** | กราฟแท่งและกราฟโดนัทสรุปข้อมูล รายงานหลักสูตร ส่งออก Excel/PDF |
| **บุคลากรและข่าวสาร** | ทะเบียนบุคลากร ข่าวประชาสัมพันธ์ และหน้าแรกที่แสดงหลักสูตรกับข่าวล่าสุด |
| **ผู้ใช้และสิทธิ์** | สมัคร/เข้าสู่ระบบด้วย ASP.NET Core Identity จัดการผู้ใช้และบทบาท (ผู้ดูแลระบบ / ผู้ใช้งานทั่วไป) |

## เทคโนโลยีที่ใช้

| ส่วน | เทคโนโลยี |
|---|---|
| **แอปพลิเคชัน** | Blazor Server (.NET 9, Interactive Server), MudBlazor 8, Bootstrap |
| **ข้อมูล** | Entity Framework Core 9, SQL Server, ASP.NET Core Identity |
| **เอกสาร** | ClosedXML (ส่งออก Excel), ExcelDataReader (นำเข้า Excel), iText 7 / iTextSharp (สร้าง PDF) |

## จุดเด่นทางเทคนิค

- **แยกชั้นบริการชัดเจน** แต่ละงานมี Service ของตัวเอง (นักศึกษา รุ่น เช็กชื่อ รายงาน ฯลฯ) ลงทะเบียนผ่าน Dependency Injection แยกจากหน้าจอ Razor
- **สร้างเอกสารอัตโนมัติ** บัตรนักศึกษา ตารางเรียน และรายงานเป็น PDF/Excel โดยตรงจากระบบ
- **นำเข้าข้อมูลจาก Excel** อ่านไฟล์แผนการเรียนที่อัปโหลดเข้าฐานข้อมูล
- **แดชบอร์ดแบบเห็นภาพ** กราฟสรุปด้วย MudBlazor Charts
- **ฐานข้อมูลที่ดูแลด้วย Migration** 32 Migration ตลอดการพัฒนา
- **ยืนยันตัวตนด้วย Identity** แยกบทบาท และตรวจสถานะการล็อกอินใหม่ระหว่างใช้งาน (Revalidating Authentication State)

## โครงสร้างโปรเจกต์

```
BlazorProjectSamathi58/
└── ProjectBlazorManage1/
    ├── Components/    หน้าจอ Razor (Pages, Layout, Account)
    ├── Service/       บริการธุรกิจของแต่ละงาน
    ├── Data/          DbContext และ Migrations
    ├── Model/         Entity และ DTO
    ├── Helper/        ตัวช่วยฝั่ง JavaScript Interop
    ├── Utility/       ค่าคงที่ เช่น ชื่อบทบาท

```

## วิธีรันบนเครื่อง

**สิ่งที่ต้องมี:** .NET 9 SDK, SQL Server (หรือ LocalDB ที่มากับ Visual Studio) และ `dotnet-ef` (`dotnet tool install --global dotnet-ef`)

```powershell
cd ProjectBlazorManage1

dotnet user-secrets init

# (ไม่บังคับ) ค่าเริ่มต้นใช้ LocalDB ถ้าต้องการฐานข้อมูลอื่นให้ตั้ง connection string เอง
dotnet user-secrets set "ConnectionStrings:DefaultConnection" "Server=(localdb)\mssqllocaldb;Database=ProjectBlazorManage;Trusted_Connection=True;MultipleActiveResultSets=true"

# สร้างตารางในฐานข้อมูล
dotnet ef database update

dotnet run
```

เปิด `https://localhost:7238`

> หน้าลงทะเบียนจะสร้างบทบาทเริ่มต้นให้เมื่อยังไม่มีบทบาทในระบบ แต่ในโค้ดไม่มีการสร้างผู้ดูแลระบบอัตโนมัติ การให้บทบาท `Admin` กับบัญชีใดบัญชีหนึ่งต้องกำหนดเองในฐานข้อมูล จากนั้นผู้ดูแลระบบจัดการผู้ใช้และบทบาทเพิ่มเติมได้ในเมนู "บทบาท" และ "ผู้ใช้งาน"
